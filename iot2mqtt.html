iot2mqtt.abstract module

Re-export facade for abstract device classes.

Provides backward compatibility by re-exporting device state classes from their protocol-specific modules. New code should import directly from the specific modules.

iot2mqtt.messenger module

Thread-safe messaging system for processing IoT messages through conditional handlers.

This module provides message types, data structures, and queue-based dispatching mechanisms for producing and consuming MQTT messages in the IoT framework.

Example

Process incoming MQTT messages by message type:

import time
import iot2mqtt as i2m

TARGET = "localhost"

def main():
    _client = i2m.mqtthelper.ClientHelper(
        i2m.mqtthelper.MQTTContext(hostname=TARGET),
        i2m.mqtthelper.SecurityContext()
    )
    _client.start()
    _refined_queue = i2m.central.get_refined_data_queue(_client)

    i2m.messenger.Dispatcher(
        input_queue=_refined_queue,
        output_queue=None,
        conditional_handlers=[
            (i2m.messenger.is_type_availability,
            lambda msg: print(f"Availability: {msg.device_id} {msg.refined}")),
        ],
    )

if __name__ == "__main__":
    main()
    for _ in range(10):
        print(".", end="", flush=True)
        time.sleep(1)

Base registry for topic configurations by protocol and message type.

Module contents

IoT to MQTT bridge framework for integrating IoT devices with MQTT-based smart homes.

Provides device registry, protocol handlers, message processing, and MQTT client management for devices across multiple protocols (Zigbee, Ring, Shelly, Somfy, Tasmota).
